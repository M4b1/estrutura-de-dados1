# Estruturas de Dados 1 (ED1)

Repositório dedicado aos códigos, estudos e resoluções de exercícios da disciplina de Estruturas de Dados 1 do Bacharelado Interdisciplinar em Inovação, Ciência e Tecnologia da UFLA. 

O objetivo principal deste repositório é consolidar os conceitos de alocação de memória e a implementação dos principais Tipos Abstratos de Dados (TADs) utilizando a linguagem C.

## Conteúdo Programático e Progresso

Aqui estão os tópicos abordados na disciplina. Conforme eu for finalizando os estudos e criando os códigos, marcarei com um "x":

- [ ] **Fundamentos de Memória**
  - [ ] Revisão de Ponteiros
  - [ ] Alocação dinâmica de memória (Vetores e Matrizes)
- [ ] **Análise de Algoritmos**
  - [ ] Introdução à notação assintótica
- [ ] **Tipos Abstratos de Dados (TADs)**
  - [ ] Conceitos, operações e representações
- [ ] **Listas**
  - [ ] Estáticas e dinâmicas
  - [ ] Sequenciais
  - [ ] Encadeadas e duplamente encadeadas
  - [ ] Circulares
- [ ] **Pilhas e Filas**
  - [ ] Implementação de Pilhas (usando arranjos e ponteiros)
  - [ ] Implementação de Filas (usando arranjos e ponteiros)
  - [ ] Aplicações práticas de pilhas e filas
